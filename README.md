# Бібліотека (Навчальний проєкт з Git)

Простий консольний застосунок на Python для обліку видачі та повернення книжок у бібліотеці. Проєкт створено в межах практичної роботи для опанування базових команд Git, налаштування pre-commit хуків та роботи з GitHub.

## Структура проєкту

- src/ — основний вихідний код програми (main.py, library.py)
- tests/ — тести та перевірка форматування коду (test_pre_commit.py)
- books/ — база даних книжок (books.json)
- config/ — файли конфігурації (settings.json)
- .pre-commit-config.yaml — налаштування лінтерів (ruff, black)

## Функціонал

- Видача книжки читачеві із зазначенням імені, назви книжки та терміну оренди (до 30 днів).
- Повернення книжки до бібліотеки.
- Базова валідація введених даних.

## Запуск проєкту

1. Клонуйте репозиторій:
  
   git clone <посилання-на-ваш-репозиторій>
   
2. Запустіть програму:
  
   python src/library.py
